Free Video Downloader — Design Foundation
Section 0 of the design structure, built as the shared source every screen inherits. Left column is light, right is dark — the same tokens, same components, same spacing. Brand personality: fast, safe, private. Clean utility, not playful, not corporate.
Assumptions: Roboto stands in for the Android system sans. Material Symbols Rounded at 24dp is the only icon set. 1dp = 1px at this scale; screens are drawn at 360dp logical width.

DECISIONS THIS FOUNDATION LOCKS IN
• One primary button per screen or sheet — never two reds competing.
• Cards use borders, not shadows. Shadow means "floating above" and only sheets/dialogs do.
• Every progress state names a remedy in plain language, not an error code.
• Destructive actions sit far from primary actions and always state the consequence.
• Touch targets ≥48dp even where the visual is 24dp.
• Dark theme is a token swap, never a separate layout.
