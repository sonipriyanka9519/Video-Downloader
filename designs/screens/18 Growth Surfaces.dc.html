DESIGN NOTES
• The share-target landing is a screen, not a sheet: it's a full task arriving from outside, and a close X returns the user to the app they came from.
• It shows the detection result inline — thumbnail, title, "Found in 0.4s" — so the loop the per-site guides teach visibly pays off.
• Rate prompt fires on the third success and names the reason ("Three downloads in"), so it reads as observation rather than nagging.
• "Send feedback" sits beside "Not now" — an unhappy user gets a private route instead of a one-star review.
• The rename offer shows one real before/after pair rather than describing the change, and stays reversible from the row menu.
• Share copy is a plain sentence, not marketing. Copy link is accent-highlighted because it's what most people actually use.
DECIDED
A shared link always stops at this screen. It pre-selects a quality so it's still one tap, but nothing downloads until the user says so — no surprise files, no surprise data use.
Remaining from the plan: unwatched badges and the weekly digest, if you want those as screens.
