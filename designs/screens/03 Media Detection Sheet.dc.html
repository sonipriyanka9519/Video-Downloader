DESIGN NOTES
• Pager arrows sit either side of the page indicator in the header — left dimmed on the first card. They appear only when more than one video is detected; swipe still works, the arrows just make it discoverable.
• One tap does everything: the primary button carries the live size, queues the job, dismisses the sheet and leaves a snackbar with View.
• Select mode is hidden until asked for — a centred "Download all 4…" text button, never a second red button competing with Download.
• In select mode one shared chip row sets quality for every item, so the user makes one decision instead of four.
• Sizes still probing show a three-dot shimmer in place of the size and never block selection — the rung stays tappable.
• Locked rungs are honest: grey, lock glyph, not selectable. When every rung is locked the primary button is replaced by a plain shield notice.
• Reopening the sheet shows anything already queued from this page with a progress ring and "Downloading…", so nothing gets queued twice.
