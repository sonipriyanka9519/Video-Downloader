Tab switcher, including private
Switch, open and close tabs — nothing more. Full-screen slide-up over the active tab, one primary action at the bottom, and a segmented control that only exists once a private tab has been opened this session.
Assumptions: page previews are placeholders for cached snapshots. No tab groups, no drag reorder. Older tabs beyond four live WebViews reload on tap — invisible here, since a tab never looks dead.

DESIGN NOTES
• Segmented control is absent until a private tab has been opened this session — panel C is what a new user sees.
• Active tab carries a 2dp accent border; in the private segment it borders in ink, since accent would read as "downloading".
• Closing: X on the card or a sideways swipe, both reversible through a snackbar Undo. Close all tabs lives in the overflow, behind a confirm.
• Private grid sits on an ink-tinted wash so the mode is unmistakable even mid-scroll, and its primary button is ink, not accent.
• Private cards are labelled Private 1, 2, 3 — enough to tell them apart, with no page title or favicon, so nothing identifying survives on screen or on disk.
• One primary action per screen: New tab. Everything else is an icon or a row.
DECIDED
Private cards use numbered labels — Private 1, 2, 3 — so a user can tell them apart without any page title or favicon being written to screen or disk.
