SCREEN 13
Storage manager
Built to prevent the storage-full uninstall. It answers three questions in order — how much am I using, what can I safely delete, what is biggest — and every action hands off to select mode rather than inventing new deletion UI.
Assumptions: "Other content" is everything else on the device, read from the system. No auto-delete rules and no cache controls — the app never deletes anything the user didn't confirm.

DESIGN NOTES
• The bar shows the app's slice honestly against the whole device — accent for our videos, ink-faint for other content, line for free.
• One suggestion, not a scoreboard: watched videos, with the count and the megabytes it would return.
• "Review & free up" is a secondary button and hands off to Screen 07's select mode, pre-checked — no new deletion UI exists here.
• Select mode arrives with a one-line accent-soft banner explaining why 18 rows are already ticked, so nothing feels automatic.
• Largest files emphasise size in semibold and keep the per-row overflow, so a single fix is one tap away.
• When there's nothing safe to suggest, the card says so instead of hiding — the screen never looks broken.
OPEN QUESTION
"Watched" means finished. Should partially watched files over, say, 90% count too — they're usually done in practice — or does that risk deleting something mid-series?
