Settings

Assumptions: rows that open the system (language, download location, default browser) hand off to Android and are labelled so the jump isn't a surprise. Private folder appears only once app lock is set.

DESIGN NOTES
• Every row's subtitle carries either its current value or its consequence — no row needs explaining elsewhere.
• Choices open as radio sheets, not new screens, and apply on tap. Only the destructive rows use dialogs.
• Rows that hand off to Android say so ("Opens Android settings"), so leaving the app is never a surprise.
• Private folder only exists once app lock is set — visible in the dark panel, absent in the light one, same list.
• "Set as default browser" disappears entirely once the app is default, rather than sitting there disabled.
• Six sections, ~two screens. That's why there is no search in settings and no nested pages.
OPEN QUESTION
Default quality is "Always ask" out of the box, which means one extra tap per download forever. Worth defaulting to "Best up to 720p" and letting the sheet override, since the sheet is one tap anyway?
