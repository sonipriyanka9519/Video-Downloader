Per-site guide & clipboard dialogs
Two interruptions, both earning their place. The guide appears only where in-browser detection is unreliable and the user needs the native app; the copied-link dialog only after the user taps the address bar, and never twice for the same link.
Assumptions: guide screenshots are placeholders for real annotated captures per site. Deep link falls back to the Play Store listing if the app isn't installed, and the button reads "Get Instagram" in that case. We never read the clipboard on cold open — Android 14+ would surface its own paste-access toast for a prompt the user didn't ask for.

DESIGN NOTES
• Guide steps are a horizontal pager, not a scroll: three short instructions, each with its own annotated capture and one accent arrow.
• Step 3 states the limit honestly — private posts can't be downloaded — instead of letting the user discover it as a failure.
• "Don't show again" is a checkbox, not a hidden preference, and is per-site: dismissing Instagram doesn't silence Facebook.
• Deep-link button is primary because it's the reliable path; Got it stays a text button so dismissing costs nothing.
• We read the clipboard only when the user taps the address bar — an act that already means "I want to go somewhere" — so the system paste toast lands on an intentional gesture.
• A declined link is never offered again — the strip's X marks that URL as refused, so there's no second prompt for the same paste.
DECIDED
No clipboard read on cold open. The copied link surfaces as a chip in the search screen when the user taps the address bar, and this dialog confirms it. Panel C is the same offer mid-page, as a dismissible strip.
