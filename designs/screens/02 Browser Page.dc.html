DESIGN NOTES
• Detection is silent: the FAB appears with one 300ms pulse and its badge counts. No toast, no auto-opening sheet, ever.
• Address pill shows the domain only, with a lock when https. Refresh becomes X while loading; tapping the pill opens Screen 04 with the full URL prefilled and selected.
• Web content keeps the site's own colours in both themes — only the chrome switches, so the dark panels still show a white page.
• Private tab is the same layout with an ink toolbar strip, a darker pill, a mask glyph before the domain and a filled tab counter.
• Forward chevron is faint when there is no forward history; it never disappears, so the toolbar doesn't reflow.
• FAB sits 16dp from the right and 16dp above the nav bar, and is hidden entirely when the count is 0.
