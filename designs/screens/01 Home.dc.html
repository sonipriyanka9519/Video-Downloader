SCREEN 01
Home — browser start page
The front door: launch a site, resume watching, jump back into recent activity. Every content row is conditional — a new install sees only the toolbar and the shortcut grid, so Home stays as light as the MVP. No FAB here: there is nothing to detect on Home.
Assumptions: 360dp screen at 1dp = 1px. Site tiles are placeholders — official brand marks drop in later at the same 56dp rounded-square. Thumbnails are placeholder frames. Status bar is the OS, drawn only for context.

DESIGN NOTES
• The address pill is the whole touch target and the only way into search — one obvious entry, no dropdown under the toolbar.
• Paste-link helper is a single line, never a dialog on Home, and never re-offered once dismissed.
• Recent Downloads is the only content row: it appears when a download exists, never as a skeleton — Home renders instantly or shows less.
• A downloading item lives in Recent Downloads with an accent bar and "Downloading…", so Home reflects live state without a second nav badge story.
• Private-tab content never appears in Recent Downloads.
• First run is deliberately near-identical to today's MVP: grid plus one hint card, no rows, no FAB.
Toolbar now matches the MVP: home, back, forward (forward faint when there is no forward history), then the address pill, tab counter and overflow. Open questions: (1) Edit mode — a fifth panel here, or its own screen with the Add-a-site sheet? (2) Real site marks: send the icon set and I'll swap the placeholders.
