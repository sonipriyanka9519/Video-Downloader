Downloads — select mode, item sheet, dialogs

Assumptions: Lock / Move to private appear only when app lock is configured. Rename keeps the extension — the dialog shows it as a fixed suffix so the field can't break the file.

DESIGN NOTES
• Select mode replaces the header, not the list: X, count, Select all. A 4-action bar covers the nav so Delete never sits beside Play.
• Selected rows tint accent-soft and their checkbox fills — two signals, no chance of miscounting.
• The item sheet header is plain surface with a 64×36 thumb and the real filename — the old orange gradient header is gone.
• Delete is the only red row in the sheet, always last, always followed by a confirm that states the consequence.
• Rename edits the stem only; the extension is a fixed chip with "Extension can't be changed" beneath.
• Sort applies on tap with no OK button, and Source in Properties is a link straight back to the page.
