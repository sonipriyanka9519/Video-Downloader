SCREEN 14
Splash and walkthrough
Four pages that teach one loop: open a site, play a video, tap the button, pick a quality. Each page carries one abstract diagram rather than a mock of the interface, so nobody mistakes the artwork for a screen they are supposed to tap.
Assumptions: shown once on first run, always reachable from the Downloads empty state and Settings. Splash caps at 1.5s and only shows its progress bar if loading exceeds 600ms.

DESIGN NOTES
• Illustrations are deliberately abstract — circles, blocks, one accent shape — so no page ever looks like a live screen the user is meant to operate. Only the Next button is tappable.
• One heading sentence per page plus one caption under the diagram. Nothing inside the artwork is labelled like a control.
• Skip sits top-right on pages 1–3 and disappears on page 4, where the primary button already ends the flow.
• Page indicator uses an accent pill for the active dot, matching the chip row's selected treatment.
• Splash is brand-only: icon, name, tagline, corner shapes at 4%. The progress bar appears only if loading passes 600ms.
• Re-entry from Settings and the Downloads empty state uses the same four pages — there is no separate help content to maintain.
DECIDED
Staying at four pages, as agreed. Artwork is now diagrammatic rather than a replica of the interface, so no one taps the picture waiting for it to respond.
