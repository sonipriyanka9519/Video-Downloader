DESIGN NOTES
• Biometric is preselected and badged Recommended; PIN is always set up too, because a fingerprint can fail.
• Keypad keys are 64dp circles in the bottom 40% of the screen — reachable one-handed, far from the back arrow.
• Mismatch turns the dots to outlines in error with one plain sentence, plus a shake. No lockout copy at four digits.
• A recovery question is set as step 3 of PIN setup, and Forgot PIN? on the lock screen answers it — the only route back in, and it never unlocks by email.
• Private mode is signposted by an ink header wash and a lock glyph, so there's no doubt which library you're in.
• Moving items is reversible: a snackbar with Undo, never a confirm dialog — nothing was destroyed.
